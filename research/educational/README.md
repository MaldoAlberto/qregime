# Material educativo y visual

> **Version historica.** `paper.pdf` / `paper.tex` es el borrador original en
> espanol y ya no se actualiza: algunas cifras fueron corregidas despues
> (por ejemplo, el 82.9% de precision LOFO retractado). La version vigente y
> citable es [`paper/paper_en.pdf`](../../paper/paper_en.pdf).

- **`paper.pdf` / `paper.tex`**: white paper de dos columnas con metodologia,
  resultados de las 7 tecnicas, y discusion (borrador historico, ver nota
  arriba).
- **`pipeline_diagram.html`**: diagrama interactivo (SVG) del pipeline
  completo -- perfilado -> banco de 7 tecnicas -> decide_regime QEM/FTQC ->
  regimen final -- con una caja de pie de pagina listando la disciplina de
  verificacion aplicada durante el proyecto (leave-one-family-out, chequeo
  de equivalencia unitaria, etc). Abrir en cualquier navegador.
